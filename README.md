# Shorts Tracker

Android app that counts the Reels / Shorts you scroll in Instagram, YouTube and Facebook and blocks them once you cross your daily limit.

- Daily limit (change with - / + on Home)
- Ring showing today's count
- Streak flame: stays lit while you stay at or under the limit
- Blocks: turn blocking on/off per app
- Everything stays on the phone, no internet permission

## Get the APK
1. Open the **Actions** tab on GitHub, pick the latest "Build APK" run.
2. Download the `ShortsTracker-debug-apk` artifact, unzip, install `app-debug.apk`.

## Turn it on
Open the app, tap **Open Accessibility Settings**, enable **Shorts Tracker**.

## Note
Reel detection looks for the Reels/Shorts player screen in each app, so it can need small tweaks when Instagram/YouTube/Facebook change their layouts.
